# Navigation

Es existiert zur Zeit nur eine sehr rudimentäre Navigation. Die einzige Seite ist die Detailseite photographers.
Die Navigation erfolgt im Wesentlich auf Basis von Links und gewissermaßen immer nach vorne. Es gibt aber keine Zurücknavigation. D.h. es ist schwierig zur vorhergehenden Seite zurückzukehren. Es sollte möglich sein, ähnlich zur zurücknaviation von photographers, zurück zur vorhergehenden Seite zu navigieren.
