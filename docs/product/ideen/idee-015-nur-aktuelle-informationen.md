# Nur aktuelle Informationen

Es sollen nur aktuellen Informationen angezeigt werden.

## Seite events

Auf der Seite 'events' werden auch vergangene Events angezeigt. Hier sollen aber nur aktuelle oder zukünftige events angezeigt werden.

## Seite Magazin

Auf der Seite sollen alle Informationen angezeigt werden. die aktuelle Implementierung soll nicht angepasst werden.

## Fotograf:innen

Auf der Detailseite der Fotograf:innen sollen alle Ausstellungen und Events, an denen sie beteiligt waren angezeigt werden. Die aktuellste Information soll oben liegen. Es werden auch vergangene oder beendete Events oder Ausstellungen angezeigt. 

## Orte

Es werden auf der Seite Orte nur laufende oder zukünftige Events oder Ausstellungen angezeigt. Vergangene Events oder beendete Ausstellungen werden nicht angezeigt. 

## Ausstellungen

Auf der Seite Ausstellungen ('exhibitions') werden nur laufende oder kommende Ausstellungen anzeigt.

## Kalender

Auf der Seite Kalender werden nur die aktuellen Veranstaltungen angezeigt. Es ist möglich, sich vergangene Veranstaltungen einblenden zu lassen. An der Implementierung wird nichts geändert.

## Ort/ Venues

Auf der Seite der Orte werden nur aktuelle und zukünftige Veranstaltungen angezeigt. Ich möchte wissen, was dort im Augenblick läuft oder ob es bald einen Termin gibt, zu dem ich hingehen möchte.
