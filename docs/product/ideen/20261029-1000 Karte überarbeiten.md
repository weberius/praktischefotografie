# Karte überarbeiten

Die Darstellung der Seite map oder Karte soll überarbeitet werden. Zur Zeit ist das Kartenfenster relativ klein und die Liste der Orte findet sich links daneben. Außerdem werden all Point-Of-Interest durch den Standart Marker dargestellt.
Das soll folgendermaßen geändert werden:
- Die Liste der Orte soll ganz verschwinden. 
- Die Karte soll sich unterhalb des Filters über die gesamte Fläche erstrecken.
- In Abhängikeit vom Typ sollen eigene Symbole in unterschiedlichen Farben angezeigt werden.
- Zur Klärung des Typs, soll es eine Legende geben
