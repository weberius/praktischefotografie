# Header und Footer

Der Header und der Footer sollen überarbeitet werden.

## Header

- Die Navigation soll durch ein Burger-Menu abgebildet werden.
- Der Name der Anwendung im Header lautet 'Zentrum für praktische Fotografie'
- Der Header soll immer im Vordergrund liegen. Wenn die Seite heruntergescrollt wird
- Der Footer soll sich am Footer von Klangland orientieren: https://github.com/weberius/klangland
- Der Footer soll nicht fest stehen, sondern kann auch aus dem Bild rausscrollen, wenn die Seite länger ist. Das entspricht dem aktuellen Verhalten.
