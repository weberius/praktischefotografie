1. Datenschutz auf einen Blick

Der Schutz Ihrer persönlichen Daten ist mir wichtig. Ich behandle personenbezogene Daten vertraulich und entsprechend der gesetzlichen Datenschutzvorschriften (DSGVO) sowie dieser Datenschutzerklärung. Verantwortlich ist der im Impressum genannte Betreiber.

2. Datenerfassung auf dieser Webseite

Keine Cookies, kein Tracking: Diese Seite setzt keine Cookies und verwendet weder Tracking noch Analysedienste. Es wird nichts dauerhaft im Browser gespeichert.

Server-Logfiles: Beim Aufruf verarbeitet der Hosting-Anbieter technisch bedingt Informationen in Server-Logdateien (z. B. IP-Adresse, Browsertyp, Referrer-URL, Uhrzeit der Anfrage).

Karte (OpenStreetMap): Auf der Seite „Karte“ lädt Ihr Browser Kartenkacheln von den Servern der OpenStreetMap-Mitwirkenden (tile.openstreetmap.org). Dabei erhält der Anbieter technisch bedingt Ihre IP-Adresse. Auf allen anderen Seiten werden keine Inhalte von Dritten nachgeladen. Die Liste der Orte steht auch ohne Karte zur Verfügung.

Die Seite wird als statische Webseite auf GitHub Pages bereitgestellt. Dabei können technisch notwendige Zugriffsdaten verarbeitet und in Protokolldateien gespeichert werden. GitHub kann dabei Dienstleister und Server außerhalb der EU einsetzen.
